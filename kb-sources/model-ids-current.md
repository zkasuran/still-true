# Naming a Claude model

Current Claude model IDs are complete as written and take no date suffix. Use
the exact string:

```
claude-opus-5
claude-sonnet-5
claude-haiku-4-5
claude-fable-5-1
```

Do not append a date suffix to these. Writing `claude-opus-5-20260401` or any
other dated variant is wrong. The dated-snapshot form belonged to the Claude 3
family and does not apply to the current models.
